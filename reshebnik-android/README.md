# Решебник

Android-приложение: калькулятор и решение заданий по фото через нейросеть Claude.

- **Калькулятор** — скобки, проценты, степени, корень, π, результат «на лету».
- **По фото** — снимок с камеры или из галереи уходит в Claude API, в ответ приходят условие, ответ и решение по шагам.

Оформление: светлая тема — тетрадный лист в клетку, тёмная — школьная доска. Тема выбирается по системной.

## Ключ API

Решение по фото работает только с ключом Claude API. Его создают в console.anthropic.com (раздел API Keys)
и вводят в приложении: значок настроек в правом верхнем углу. Ключ хранится в закрытых настройках приложения
на телефоне, в APK его нет. Запросы платные — по тарифам Anthropic.

Модель задана в `ClaudeSolver.MODEL`.

## Сборка

Нужны JDK 17+ и Android SDK (путь — в `ANDROID_HOME` или в `local.properties`, строка `sdk.dir=...`).

```bash
./gradlew :app:assembleRelease     # APK: app/build/outputs/apk/release/app-release.apk
./gradlew :app:testDebugUnitTest   # тесты; снимки экранов — в app/build/screenshots
```

Release подписан отладочным ключом — этого хватает, чтобы поставить APK на свой телефон.
Отладочный ключ у каждого компьютера свой, поэтому сборку с другого компьютера поверх старой
поставить не получится: сначала удалите приложение. Для публикации в магазине нужен собственный ключ подписи.

## Устройство

| Путь | Что там |
|---|---|
| `calc/CalcEngine.kt` | разбор и вычисление выражения |
| `calc/CalcState.kt` | логика клавиш и форматирование выражения |
| `solver/ClaudeSolver.kt` | запрос к Claude API (официальный SDK `anthropic-java`), подсказка для модели, схема ответа |
| `solver/ImagePrep.kt` | уменьшение и поворот фото перед отправкой |
| `solver/SolverViewModel.kt` | состояния экрана «По фото» |
| `ui/` | экраны, тема, компоненты |

Шрифты Onest и PT Serif распространяются по лицензии SIL OFL 1.1, тексты — в `licenses/`.
