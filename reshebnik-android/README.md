# Решебник

Android-приложение: калькулятор и решение заданий через нейросеть Claude.

## Что умеет

**Калькулятор**
- скобки, проценты, степени, корни, π, результат «на лету»;
- лента прошлых вычислений прямо на листе: нажал на строку — результат подставился;
- инженерный режим при повороте телефона: sin, cos, tg и обратные, ln, lg, n!, e, |x|, ∛, градусы и радианы.

**По фото**
- своя камера с рамкой и фонариком, фото из галереи или условие текстом;
- обрезка и поворот снимка перед отправкой;
- режимы «Решить задание» и «Проверить моё решение» (находит шаг с ошибкой);
- «Быстро» (Claude Haiku, дёшево) или «Точно» (Claude Opus);
- решение появляется по мере написания, формулы набраны как в учебнике;
- вопросы по решению и кнопка «Объяснить подробнее» у каждого шага;
- «Поделиться» картинкой или текстом.

**История** — решённые задания с фото, ответом и вопросами; лежит только на телефоне.

Оформление: светлая тема — тетрадный лист в клетку, тёмная — школьная доска. Тема выбирается по системной.

## Ключ API

Решение работает только с ключом Claude API. Его создают в console.anthropic.com (раздел API Keys)
и вводят в приложении: значок настроек в правом верхнем углу. Ключ хранится на телефоне зашифрованным
(Android Keystore), в APK его нет. Запросы платные — по тарифам Anthropic.

Модели заданы в `ClaudeSolver`: `PRECISE_MODEL` и `FAST_MODEL`.

## Сборка

Нужны JDK 17+ и Android SDK (путь — в `ANDROID_HOME` или в `local.properties`, строка `sdk.dir=...`).

```bash
./gradlew :app:assembleRelease     # APK: app/build/outputs/apk/release/app-release.apk
./gradlew :app:testDebugUnitTest   # тесты; снимки экранов — в app/build/screenshots
```

### Подпись

Обновление ставится поверх установленной версии, только если APK подписан тем же ключом.
Сборка берёт ключ из файла `signing/release.keystore` (в репозиторий он не входит). Если файла нет,
APK подписывается отладочным ключом этого компьютера — такую сборку поверх прежней не поставить,
старое приложение придётся удалить вместе с историей и ключом API.

### Проверка без сервера Anthropic

Адрес сервера можно подменить при сборке, чтобы проверить приложение на локальной заглушке:

```bash
./gradlew :app:assembleRelease -PapiBaseUrl=http://10.0.2.2:8765
```

`10.0.2.2` — это компьютер, на котором запущен эмулятор. В такой сборке разрешён незашифрованный HTTP;
в обычной он запрещён.

## Устройство

| Путь | Что там |
|---|---|
| `calc/CalcEngine.kt` | разбор и вычисление выражения |
| `calc/CalcState.kt` | логика клавиш и форматирование выражения |
| `math/LatexParser.kt` | разбор формул из ответа нейросети (подмножество LaTeX) |
| `math/MathLayout.kt` | раскладка и рисование формул: дроби, корни, степени, скобки, системы |
| `math/MathPlain.kt` | формула обычным текстом — для копирования и «Поделиться» |
| `solver/ClaudeSolver.kt` | запросы к Claude API (официальный SDK `anthropic-java`), подсказки для модели, схемы ответа |
| `solver/Json.kt` | разбор ответа, в том числе оборванного посередине, пока он ещё пишется |
| `solver/SolverViewModel.kt` | состояния экрана «По фото» |
| `data/HistoryStore.kt` | история решений на диске |
| `data/KeyCipher.kt` | шифрование ключа API |
| `ui/` | экраны, тема, компоненты |

Шрифты Onest, PT Serif и STIX Two Math распространяются по лицензии SIL OFL 1.1, тексты — в `licenses/`.
