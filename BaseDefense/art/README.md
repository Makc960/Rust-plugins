# Графика

Все картинки игры лежат в одном атласе: `engine/src/main/resources/sprites/atlas.png`
и его оглавлении `atlas.txt` (имя, место в атласе и видимая часть каждой картинки;
128 пикселей атласа на клетку карты). Атлас собирает `build_atlas.py`.

## Откуда картинки

Бесплатные паки [Kenney](https://kenney.nl), лицензия
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (общественное достояние,
можно и в платных играх; упоминать автора не обязательно, но мы упоминаем — здесь и в описании игры в магазине):

- **Tower Defense (top-down)** — ракеты, деревья, камни, огонь, самолёты;
- **Top-down Shooter** — солдаты для отрядов, люди и роботы для врагов;
- **Top-down Tanks Redux** — земля и дороги всех миров, мешки с песком для окопов, броневик, огнемётный танк, взрывы, дым, мины;
- **Robot Pack** — гусеничные роботы вулкана: бурильщик, джаггернаут и титан;
- **Game Icons** и **Game Icons Expansion** — белые иконки интерфейса (`icon.*`), игра красит их сама.

Векторные листы паков рендерятся в 4 раза крупнее (поэтому картинки чёткие), каждая
картинка поворачивается лицом вправо и центрируется. Для пустыни и севера скрипт
перекрашивает траву в снег, камни в песчаник, деревья в заснеженные; для вулкана — траву
в пепел, асфальт в шлак, камни в базальт с лавовыми трещинами, деревья в обугленные, а
саламандру одевает в серебристый огнеупорный костюм с оранжевым жаром вокруг; для руин города — траву
в бетон с трещинами и осколками кирпича, асфальт темнее, камни в бетонные плиты с ржавой арматурой,
а вместо деревьев рисует сгоревшие машины. Байкер (мотоцикл и шлем дорисованы под человечка из пака),
огнемётный танк (корпус танка из пака с баками и соплом) и дирижабль нарисованы скриптом. Солдат из пака
переодевается в цвет своего отряда, а оружие (гранатомёты, огнемёты, ПЗРК, тесла-винтовки,
снайперские винтовки и прочее) дорисовано в том же стиле прямо в скрипте, как и радар,
вертолёт, кактус, вагонетка снабжения и шахта. Иконки сердца, черепа, книги, календаря, бесконечности, короны
и шевронов нарисованы скриптом в стиле Game Icons.

## Как пересобрать

Нужны Python 3 с `pillow` и `numpy`, Node.js с `playwright` (Chromium рендерит SVG).

```sh
git clone --filter=blob:none --sparse https://github.com/ETdoFresh/kenney.nl kenney
git -C kenney sparse-checkout set tower-defense-top-down topdown-shooter kenney_topdowntanksredux robot-pack gameicons gameicons-expansion
npm install playwright && npx playwright install chromium
python3 build_atlas.py kenney work ../engine/src/main/resources/sprites --preview preview.png
```

`ETdoFresh/kenney.nl` — зеркало паков на GitHub (собиралось с коммита `45df48c`).
`work` — папка для промежуточных рендеров, их можно переиспользовать между запусками.
`preview.png` — все картинки на одном листе в настоящем размере, удобно проверять глазами.

## Иконка

Иконку игры (боец в каске за мешками с песком, позади золотой знак с шевронами) нарисовала
нейросеть по описанию автора. Исходники лежат в `icon/`:

- `icon.webp` — иконка целиком, квадрат с фоном до краёв;
- `icon-cutout.webp` — боец, мешки и знак на прозрачном фоне.

`build_icon.py` собирает из них:

- иконку Android (`app/src/main/res/mipmap-*`). Это адаптивная иконка: картинка занимает видимые
  72 dp слоя 108 dp, под ней лежит размытая копия на случай, если лаунчер сдвинет слой;
- эмблему заставки при запуске (`drawable-xxxhdpi/splash_emblem.png`), вписанную в круг 160 dp,
  который рисует Android 12 и новее;
- значок 512×512 для магазинов (`store/graphics/icon-512.png`).

Монохромная иконка для тем Android 13 осталась прежней: каска и шевроны
(`drawable/ic_launcher_monochrome.xml`).

```sh
python3 build_icon.py --preview preview.png
```

На `preview.png` видно иконку в круге, в скруглённом квадрате и в размере 48 px, а также заставку.
