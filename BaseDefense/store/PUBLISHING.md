# Как выложить игру в Google Play

Всё, что можно было сделать в коде, уже сделано: target API 36, категория «игра», AAB, тексты, картинки
и политика конфиденциальности лежат в этой папке. Остальное делается в твоих аккаунтах.

## 1. Ключ загрузки (один раз, у себя на компьютере)

Ключ из репозитория (`app/base-defense.keystore`) публичный и годится только для APK «для своих».
Для Google Play нужен свой секретный ключ. Нужна Java (команда `keytool`):

```
keytool -genkeypair -v -keystore upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
```

Запомни пароль. Файл `upload.jks` храни в надёжном месте и **никогда не клади в репозиторий**.

## 2. Секреты в GitHub

Репозиторий → Settings → Secrets and variables → Actions → New repository secret:

| Имя | Что вписать |
|---|---|
| `UPLOAD_KEYSTORE_BASE64` | вывод `base64 -w0 upload.jks` (на Mac: `base64 -i upload.jks`) |
| `UPLOAD_KEYSTORE_PASSWORD` | пароль хранилища |
| `UPLOAD_KEY_ALIAS` | `upload` |
| `UPLOAD_KEY_PASSWORD` | пароль ключа (обычно тот же) |

После этого каждая сборка в Actions, кроме APK, кладёт артефакт **BaseDefense-GooglePlay** с файлом
`BaseDefense.aab`, подписанным твоим ключом. Номер версии (versionCode) растёт сам с каждой сборкой.

## 3. Аккаунт разработчика

1. https://play.google.com/console — регистрация, разовый взнос 25 $ и проверка личности.
2. Для новых личных аккаунтов действует правило: перед выпуском в общий доступ нужен **закрытый тест
   минимум с 12 тестировщиками, которые не выходят из теста 14 дней подряд**. Позови друзей заранее.

## 4. Приложение в консоли

- Создать приложение: язык по умолчанию — русский (или английский), тип — игра, бесплатная.
- **Карточка**: название, краткое и полное описание из `listing-ru.md` и `listing-en.md`
  (английский перевод добавляется в «Переводах»).
- **Графика** из `graphics/`: значок `icon-512.png`, баннер `feature-graphic.png`,
  скриншоты телефона `screen-ru-*.png` и `screen-en-*.png`.
- **Политика конфиденциальности**: ссылка на `PRIVACY.md` в этом репозитории,
  `https://github.com/Makc960/Rust-plugins/blob/ccr-bdac1a50-wqgotp/BaseDefense/store/PRIVACY.md`.
  Ссылка должна открываться, пока игра в магазине: ветку не удалять, а если её сольют в другую, поменять ссылку.
- **Безопасность данных**: приложение не собирает и не передаёт данные.
- **Реклама**: нет. **Покупки**: нет.
- **Возрастной рейтинг**: анкета IARC. Насилие — мультяшное, без крови (враги исчезают), без азартных игр и чатов.
- **Целевая аудитория**: 13+ (если отметить детей, появятся дополнительные требования семейной программы).
- **Категория**: Игры → Стратегии.

## 5. Выпуск

1. «Тестирование → Закрытое тестирование» → новый выпуск → загрузить `BaseDefense.aab`.
   Google Play App Signing включится сам: Google хранит ключ подписи, а ты подписываешь загрузки ключом `upload.jks`.
2. Добавить список тестировщиков (их почты Google), отправить им ссылку-приглашение.
3. Через 14 дней с 12+ тестировщиками — «Запросить доступ к рабочей версии», ответить на вопросы о тесте.
4. После одобрения — выпуск в рабочую версию.

# Как выложить игру в RuStore с VIP и покупками

Магазин есть только в версии из RuStore: VIP (подписка на месяц или навсегда), командиры и набор новобранца,
через платёжный SDK RuStore (Pay SDK). В Google Play его нет: там нельзя принимать оплату мимо Google Play Billing,
командиры там открываются только за звёзды. APK с GitHub показывает магазин и отправляет за покупками в RuStore.

1. **Аккаунт разработчика RuStore** (https://console.rustore.ru) и приложение «Оборона базы» в консоли.
2. **Платежи**: во вкладке «Разработчик» подключить монетизацию. Для выплат нужна самозанятость или ИП
   и реквизиты для перевода денег.
3. **Товары**: в разделе приложения о платежах создать их с такими ID (ID должны совпадать точно):

   | ID | Что это | Тип | Цена |
   |---|---|---|---|
   | `vip_month` | VIP на месяц | подписка, период 1 месяц | 50 ₽ |
   | `vip_forever` | VIP навсегда | непотребляемый товар | 399 ₽ |
   | `starter_pack` | Набор новобранца: инженер Ковалёва и 15 очков улучшений | непотребляемый товар | 99 ₽ |
   | `commander_engineer` | Командир: инженер Ковалёва | непотребляемый товар | 149 ₽ |
   | `commander_grom` | Командир: капитан Гром | непотребляемый товар | 149 ₽ |

   Цены зашиты и в игре (`Product` в `engine/.../Shop.kt`): если поменяешь цену в консоли, поменяй и там.
4. **ID приложения**: число в адресной строке консоли после `/apps/`, у «Обороны базы» это `2063772062`. Оно уже
   вписано в `app/build.gradle.kts` (`rustoreAppId`), и каждая сборка в Actions с секретами ключа кладёт артефакт
   **BaseDefense-RuStore** с файлом `BaseDefense-RuStore.apk`.
5. **Ключ**: RuStore-сборка подписывается тем же секретным ключом загрузки, что и сборка для Google Play
   (секреты из шага 2 выше). Платежи RuStore работают только в сборках с той подписью, что прошла модерацию,
   поэтому все версии для RuStore должны подписываться этим ключом.
6. **Тест до выпуска**: открытый бета-тест по ссылке RuStore даёт только игре, у которой уже есть опубликованная
   версия. До первой публикации есть закрытое альфа-тестирование: «Тестирование → Альфа-тестирование → Альфа-версии →
   Загрузить версию» → `BaseDefense-RuStore.apk` → «Отправить на проверку», потом «Тестировщики → Пригласить
   тестировщика» и VK ID через запятую. Тестировщики ставят игру из приложения RuStore.
7. **Выпуск**: загрузить `BaseDefense-RuStore.apk`, заполнить карточку (тексты из `listing-rustore.md`, в них есть VIP;
   картинки из `graphics/`), указать политику конфиденциальности и отправить на модерацию. Следующие версии можно сначала давать в бета-тест.
8. Оплата заработает после модерации. Игрок нажимает «Оформить VIP» или «Купить», платит картой, через СБП или SberPay,
   входит через VK ID (подписки в RuStore требуют вход), и покупка включается сама. Отменить подписку можно в RuStore.
   «Восстановить покупки» на экранах VIP и командиров возвращает купленное на новом телефоне.
