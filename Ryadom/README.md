# Рядом

Приложение для Android: друзья видят друг друга на карте со спутника. Ты добавляешь друга по коду
или ссылке, он подтверждает, и вы оба видите, кто где: на карте-гибриде (снимки со спутника, поверх
них дороги и подписи на русском), с расстоянием, временем последнего обновления и зарядом телефона.

- **Без телефона и почты.** Аккаунт — это имя и цвет. У каждого есть код друга `XXXX-XXXX` и ссылка
  `https://ice-rust.store/ryadom/add/XXXX-XXXX`.
- **Только взаимные друзья.** Местоположение видят лишь те, с кем дружба подтверждена с обеих сторон.
- **«Скрыть меня»** одной кнопкой на главном экране или в уведомлении: друзья видят, что ты скрыт, но
  не где ты.
- **Работает в фоне.** Пока показ включён, телефон примерно раз в минуту (или после того, как ты
  сдвинулся на 30 м) отправляет точку на сервер. Для этого есть постоянное уведомление. Новые заявки в
  друзья приходят уведомлениями.
- **Хранится только последняя точка.** Истории перемещений нет. «Удалить аккаунт» стирает всё сразу.

## Как устроено

```
server/   сервер на Node.js без зависимостей: аккаунты, друзья, заявки, последние точки
web/      интерфейс: страница с MapLibre GL, работает в WebView приложения (и в браузере для проверки)
app/      оболочка Android: WebView, геолокация, фоновая служба показа, уведомления, ссылки-приглашения
store/    иконка и тексты для RuStore
```

**Карта.** Гибрид собирается из двух бесплатных источников без ключей: спутниковые снимки
[Esri World Imagery](https://www.arcgis.com/home/item.html?id=10df2279f9684e4a9f6a7f08febac2a9) и векторная карта
[OpenFreeMap](https://openfreemap.org) (данные © участники OpenStreetMap). С неё берутся дороги, границы и подписи
по-русски. Также есть вид «Спутник» (только снимки) и «Схема» (обычная карта).

Почему не Яндекс Карты: в Yandex MapKit спутник и гибрид разрешены только приложениям самого Яндекса,
а бесплатный JavaScript API Яндекса ограничен несколькими сотнями загрузок карты в день.

**Адреса** в карточке друга даёт [Photon](https://photon.komoot.io) (адреса OpenStreetMap).

## Сервер

Стоит на том же VPS, что и сайт, по адресу `https://ice-rust.store/ryadom`. Сайт при этом не меняется:
в его конфигурацию nginx добавляется одна строка `include`.

```bash
cd ~/Rust-plugins && git pull
sudo bash Ryadom/server/deploy/install.sh
```

Скрипт ставит Node.js, если его нет, и запускает службу `ryadom` на `127.0.0.1:8790` от отдельного
пользователя. Данные хранятся в `/var/lib/ryadom`, каждый день делается копия в `/var/backups/ryadom`.
Повторный запуск обновляет сервер, аккаунты и друзья сохраняются. Другой адрес можно задать так:
`install.sh friends.example.ru` или `install.sh example.ru/friends`.

```bash
journalctl -u ryadom -f          # журнал
systemctl restart ryadom         # перезапуск
```

Страницы сервера: `/add/КОД` — приглашение с кнопкой «Открыть в приложении», `/privacy` — политика
конфиденциальности (ссылка на неё нужна для RuStore).

## Сборка

GitHub Actions (`.github/workflows/ryadom.yml`) на каждый push прогоняет тесты сервера и интерфейса,
собирает APK и выкладывает его в релиз `ryadom`. Если заданы секреты ключа загрузки, рядом появляется
`Ryadom-RuStore.apk`. Адрес сервера берётся из переменной репозитория `RYADOM_SERVER`, по умолчанию
`https://ice-rust.store/ryadom`.

Локально:

```bash
cd web && npm ci && npm test             # логика интерфейса
cd ../server && npm test                 # сервер
cd ../web && node tools/build.mjs dist && node e2e/run.mjs dist shots   # два «телефона» в Chromium
./gradlew :app:assembleRelease -Pserver=https://ice-rust.store/ryadom
```

Сквозная проверка (`web/e2e/run.mjs`) поднимает настоящий сервер. Анна и Борис регистрируются,
добавляют друг друга по коду, видят друг друга на карте, Борис скрывается и удаляет аккаунт. Действия
Бориса идут через имитацию моста Android, так проверяется и договорённость между страницей и Kotlin.
