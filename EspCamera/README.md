# ESP Camera

Android-приложение: открывает камеру и обводит всё, что видит, рамками в стиле ESP.
Нейросеть (EfficientDet-Lite0, 80 типов объектов COCO) работает прямо на телефоне, интернет не нужен.

Что рисуется:

- рамка (углы или полная) цветом по типу: люди красные, транспорт оранжевый, животные жёлтые, остальное голубое;
- название и номер объекта, уверенность в процентах и полоска уверенности слева от рамки;
- примерная дистанция для объектов с известным размером (человек, машина, стул, бутылка и т.д.);
- линии от низа экрана к каждому объекту;
- прицел в центре: объект под ним захватывается как цель, сверху справа появляется карточка цели.

Кнопки внизу: фильтр (всё / люди / техника / звери / вещи), вид рамок, линии, передняя/задняя камера.
Настройки запоминаются.

## Установка

1. Открой на телефоне релиз **ESP Camera**: `https://github.com/Makc960/Rust-plugins/releases/tag/esp-camera`.
2. Скачай `EspCamera.apk` и открой его. Android попросит разрешить установку из браузера, разреши.
3. Запусти приложение и дай доступ к камере.

Каждый пуш в `EspCamera/` пересобирает APK в GitHub Actions и обновляет этот релиз.
Новая версия ставится поверх старой: все сборки подписаны одним ключом `app/esp-camera.keystore`.
Ключ лежит в открытом репозитории, поэтому он годится только для домашней установки, не для Google Play.

## Сборка вручную

Нужны JDK 17 и Android SDK (проще всего открыть папку `EspCamera` в Android Studio).

```
cd EspCamera
./gradlew assembleRelease
```

Модель `efficientdet_lite0.tflite` скачивается в `app/src/main/assets/` при первой сборке.
APK появится в `app/build/outputs/apk/release/`.

Дистанция считается по формуле камеры-обскуры: реальная высота объекта × фокусное расстояние в пикселях / высота рамки.
Это оценка: она точна, когда объект виден целиком и стоит прямо.
